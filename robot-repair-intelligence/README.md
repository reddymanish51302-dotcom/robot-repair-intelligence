# AeroTech Maintenance Intelligence

Outcome-driven maintenance intelligence for the fictional AeroTech AT-600 industrial robot arm.

## What it does

The application helps a human maintenance technician investigate recurring robot faults by using historical maintenance experience stored in Hindsight.

## Workflow

Current Incident  
↓  
Hindsight Memory  
↓  
Historical Evidence  
↓  
Next Diagnostic Action  
↓  
Technician Outcome  
↓  
New Experience Stored in Hindsight

## Key Features

- Historical maintenance memory
- Memory ON/OFF comparison
- Evidence from previous repair cases
- Outcome-aware recommendations
- Technician feedback loop
- Synthetic maintenance dataset

## Tech Stack

- Python
- Streamlit
- Hindsight
- Hindsight Cloud
- Synthetic maintenance data

## Important

All robot models, fault codes, technicians, and maintenance records in this project are synthetic.
